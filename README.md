# 🚀 AI-Powered Data Analytics Platform

An end-to-end AI-driven analytics platform that automates **data cleaning, exploratory data analysis (EDA), visualization, and insight generation** for user-uploaded datasets. The platform transforms raw datasets into meaningful analytical insights using machine learning workflows, statistical analysis, and Large Language Models (LLMs).

---

# 📌 Project Overview

Traditional data analysis requires significant manual effort for:

* Cleaning datasets
* Handling missing values
* Performing exploratory analysis
* Creating visualizations
* Generating business insights

This project solves that problem by building an intelligent analytics system capable of:

* Automatically preprocessing datasets
* Performing statistical analysis
* Generating interactive visualizations
* Producing AI-generated insights
* Allowing conversational data exploration using natural language queries

The platform is designed for students, analysts, researchers, and non-technical users who want faster and smarter data analysis.

# 📊 Workflow

## Step 1: Upload Dataset

The EDA engine computes:

* Summary statistics
